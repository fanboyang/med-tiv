# Med-TIV 单验证器复现计划

目标：在237 `/data/fby/med-tiv` 完成 Qwen2.5-7B-Instruct 验证器的两轮 Dr.GRPO，并使用冻结 Qwen2.5-7B-Instruct 复现四项主表评测。不训练其他基模，不跑baseline。

架构：保留作者 VeRL-Tool 训练、检索及推理实现；在 reproduction 中增加数据、配置和编排入口。源码经本地提交、GitHub fork、云端pull同步；数据、模型和原始结果留云端。

- [ ] 环境：独立Python3.10、vLLM0.11、Torch2.8、Transformers4.57，安装作者包并做必要导入检查；检索环境独立。
- [ ] 数据：下载原始MedPRM、MedRAG PubMed/Textbooks、四项测试集；验证来源字段及标签。按问题划分内部验证集，禁止测试集进入训练/课程筛选。
- [ ] 模型：下载默认8B验证器、冻结7B生成器、MedCPT query/article encoder；检查模型配置与分片完整性，GPU可用后实载。
- [ ] 奖励修正：先写最小测试覆盖正确、错误、格式缺失、标签溢出和提示词污染，再按论文Rc×Rf实现独立奖励函数并接入仅response评分。
- [ ] 训练数据：先测试标签与prompt隔离，生成作者要求的parquet；G=8筛选奖励有变化的样本，按标签各10K，每轮重新筛选，不足20K显式失败。
- [ ] 配置：第一轮n=5，第二轮n=8；每轮5 epochs、batch256、lr1e-6、top_p0.95；模型 EOS由tokenizer读取，禁止Qwen硬编码；只管理项目自己创建的进程。
- [ ] 评测：冻结Qwen每题32候选，训练后验证器hard weighted SC，3次独立运行；全拒绝按作者实现退回全体投票并单列次数；解析失败显式标记，全分母不删题。
- [ ] 执行：GPU当前被占用，先准备依赖数据，训练等待空闲4卡；smoke通过才正式跑。保留失败记录，禁止换协议追分。
- [ ] 检查并提交：只跑相关单元测试、脚本语法和必要真实链路；原始资产不入Git，记录commit、版本、样本数和运行状态，不新增哈希。
